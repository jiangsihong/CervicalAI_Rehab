# CervicalAI Frontend

零依赖静态前端，对接 `../backend` 中的 Flask API。可以直接双击
`index.html` 打开，也可以通过本地静态服务器访问。

修改 `app.js`、`api.js` 或 `icons.js` 后，先重新生成浏览器脚本：

```powershell
node .\build.cjs
```

## 启动

先启动后端：

```powershell
cd E:\26_create\CervicalAI_Rehab\backend
.\start_backend_realheponet.bat
```

再启动前端静态服务器：

```powershell
cd E:\26_create\CervicalAI_Rehab\frontend
python -m http.server 5173
```

浏览器访问 `http://127.0.0.1:5173`。

默认后端地址是 `http://127.0.0.1:5000`，可在界面右上角的连接设置中修改。

## 已接入接口

- 用户注册、登录、资料更新、密码修改
- 注册及登录邮箱验证码、发送冷却、有效期及错误次数限制
- 登录后资料不完整时优先进入个人中心，支持稍后填写
- 图片姿态检测与模型状态
- 浏览器摄像头逐帧姿态检测
- 摄像头检测历史、会话详情、三轴统计与角度变化曲线
- 六方向评估提交
- 评估历史、详情、摘要和趋势

公开页面仅面向患者，不展示医生或管理员入口。新注册账号由后端固定为患者。
注册用户名与姓名或称呼分开填写，登录支持用户名或注册邮箱。
注册和登录均需要真实邮箱验证码；先按照 [邮箱登录配置说明](../backend/EMAIL_LOGIN.md) 配置平台发件服务并重启后端。
支持常见收件邮箱，不需要为每一种收件邮箱单独配置发件服务。未配置邮件服务时不会跳过验证。

浏览器摄像头模式使用 `getUserMedia` 在访问者设备采集画面，再调用 `/api/assessment/pose/image`。

每次启动到停止摄像头生成一条独立记录；切换页面或检测方式时也会结束记录。
登录用户通过 `/api/assessment/pose/sessions` 保存到账号，游客仅保存在当前浏览器（最近 100 次）。
每 5 秒保存进度，刷新或异常关闭后可查看最后已保存的进度。保存失败时暂存在本机，进入历史记录页会重试同步。
记录包含起止时间、时长、检测帧数、有效帧数、三轴平均值及范围、最多 300 个曲线采样点，不保存摄像头视频。
这些记录不会参与六方向活动度评估的健康分级或趋势统计。首次使用新版本请重启后端，自动创建 `camera_sessions` 表，保留现有数据。
